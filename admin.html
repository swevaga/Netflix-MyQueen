ℹ️ Cara Pakai

  1. Isi Owner / Repository / Branch / Token GitHub, lalu Tes Koneksi.
  2. Klik Muat Data dari GitHub — semua konten situs diambil dari repo.
  3. Edit konten: Berita (tanggal, judul, isi, video opsional) · Foto Series (upload foto + rasio) · Video Movies (upload video + thumbnail) · Musik (path/URL lagu + judul).
  4. Media foto/video di-upload langsung lewat drag & drop / pilih file — path otomatis terisi: Foto Series & thumbnail → src/images/photo, Video Movies → src/videos/moviespage, Video Berita → src/videos/newsandpopularpage. Musik tetap path/URL (file sudah ada di repo/hosting).
  5. Klik Simpan Perubahan ke GitHub — commit dibuat otomatis (Vercel auto re-deploy ±1 menit).

⚠️ Token hanya disimpan di browser kamu. Jangan pernah menaruh token di dalam file repo.
