ℹ️ Cara Pakai

  1. Isi Owner / Repository / Branch / Token GitHub, lalu Tes Koneksi.
  2. Klik Muat Data dari GitHub — semua konten situs diambil dari repo.
  3. Edit konten: Berita (tanggal, judul, isi, video opsional) · Foto Series (path/URL foto + rasio) · Video Movies (path/URL video + thumbnail) · Musik (path/URL lagu + judul).
  4. Media diisi sebagai path/URL — file harus sudah ada di repo atau hosting eksternal (tidak di-upload dari panel ini). Preview muncul otomatis saat path diketik.
  5. Klik Simpan Perubahan ke GitHub — commit dibuat otomatis (Vercel auto re-deploy ±1 menit).

⚠️ Token hanya disimpan di browser kamu. Jangan pernah menaruh token di dalam file repo.
