Izin Akses Perangkat

Untuk melindungi panel ini dari peretas, bot DDOS, dan percobaan brute-force PIN, situs meminta izin mengumpulkan identitas perangkat Anda: IP publik dan fingerprint perangkat (canvas/WebGL/info browser). Data hanya digunakan untuk keamanan dan daftar blokir.

Catatan: browser TIDAK mengungkap IMEI/MAC asli (kebijakan privasi). Sebagai gantinya dipakai fingerprint + IP — cukup untuk memblokir pelaku percobaan PIN berulang.

✍️ Teks Situs

Ubah semua kata-kata di index.html (hero + More Info + judul Play), play.html, newsandpopular.html, dan mylist.html — termasuk notifikasi navbar. Disimpan ke src/data/site-text-data.js lewat GitHub.

Setelah selesai klik Simpan Perubahan ke GitHub di kartu Koneksi GitHub. Halaman memakai nilai dari file ini; field kosong memakai teks bawaan di HTML-nya.

🚫 Daftar Blokir Perangkat

Kelola daftar IP / IMEI / MAC Address / Fingerprint yang diblokir. Disimpan ke src/data/blocked-devices.json. Perangkat yang cocok otomatis melihat layar blokir saat membuka admin.

⚠️ Browser TIDAK mengungkap IMEI/MAC asli perangkat ke situs web mana pun (kebijakan privasi browser). Sebagai gantinya, panel ini memakai fingerprint perangkat (canvas + WebGL + info browser) dan IP publik — keduanya cukup untuk memblokir pengguna yang mencoba PIN berulang kali.

🛡️ Daftar IP Terblokir (Server)

Dicatat otomatis oleh Vercel API (/api/post.js) ke src/data/banned_ips.json setelah 3x salah PIN (lapisan keamanan server). Kelola / unban / unduh log di sini.

Klik Muat dari API untuk melihat daftar IP yang diblokir di server.

🔐 Ganti PIN

PIN disimpan di localStorage browser ini sebagai hash SHA-256 — PIN asli TIDAK pernah ada di kode. Default bawaan (hash): d03f21ae7af2e2199935eee2e74e863e45cdda7cad26f866a0df8b867b9bbfea. Setelah 3x salah, perangkat ini diblokir permanen (localStorage + sessionStorage + cookie).

🧹 Keamanan & Privasi

Hapus token GitHub, konfigurasi repo, PIN, izin perangkat, dan penanda blokir yang tersimpan di browser ini. Setelah dibersihkan, panel kembali ke layar PIN.

ℹ️ Cara Pakai

  1. Isi Owner / Repository / Branch / Token GitHub, lalu Tes Koneksi.
  2. Klik Muat Data dari GitHub — semua konten situs diambil dari repo.
  3. Edit konten: Berita (tanggal, judul, isi, video opsional) · Foto Series (upload foto + rasio) · Video Movies (upload video + thumbnail) · Musik (upload drag & drop).
  4. Semua media di-upload langsung lewat drag & drop / pilih file — tidak ada input path/URL manual. Folder otomatis: Foto Series & thumbnail → src/images/photo, Video Movies → src/videos/moviespage, Video Berita → src/videos/newsandpopularpage, Musik → src/audio. File otomatis dinamai ulang sesuai folder (placeholder{RASIO}_N / videoN / musikN).
  5. Klik Simpan Perubahan ke GitHub — commit dibuat otomatis (Vercel auto re-deploy ±1 menit).

⚠️ Token hanya disimpan di browser kamu. Jangan pernah menaruh token di dalam file repo.
